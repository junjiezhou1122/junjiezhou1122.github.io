# Site-bloat audit (read-only, 2026-10-21)

## Executive finding

The repository is still a full al-folio starter with a thin first-party site layered on top. The public product currently needs only About (English/Chinese), Blog archive (English/Chinese), seven post source files (four English/three Chinese), the portrait/QR/font/CSS/JS assets, and Giscus/RSS/sitemap support. The build currently carries 44 direct gem declarations, 22 workflow files (1,637 YAML lines), template collections and fixture data, and 53,974,645 bytes (51.5 MiB) of tracked assets.

This is an inventory, not a deletion. Candidate removals should be done in a branch, then rebuilt and checked against the route list below.

## Measured state

- `git ls-files`: **230 tracked files**.
- Direct `gem` declarations in `Gemfile`: **44**. The Gemfile groups include Jekyll plugins plus 19 `al_*` gems, many for unused features (CV, Distill, citations, search, charts, math, newsletter, Marimo, RTL, etc.).
- `.github/workflows`: **22 files, 1,637 lines**. `deploy.yml` alone installs Ruby, Python, Node, ImageMagick, nbconvert, PurgeCSS and builds the whole starter. `unit-tests.yml` runs eight plugin/compatibility suites.
- Tracked assets: **43 files, 53,974,645 bytes (51.5 MiB)**. Clear first-party runtime assets are 9 files / **1,985,104 bytes**: `assets/css/editorial-site.css` (844 lines), `assets/css/language-switcher.css`, `assets/css/wechat-dialog.css`, `assets/js/site-language.js`, `assets/js/wechat-dialog.js`, Hanken font + license, portrait source/QR. The generated responsive portrait files are ignored/untracked outputs when present.
- Largest tracked template/demo assets: `assets/video/tutorial_al_folio.mp4` **25,991,824 bytes**; `assets/img/prof_pic_color.png` **14,382,922**; `assets/plotly/demo.html` **4,231,458**; `assets/img/prof_pic.jpg` **2,309,396**; `assets/video/pexels-engin-akyurt-6069112-960x540-30fps.mp4` **1,539,606**; `assets/audio/epicaly-short-113909.mp3` **915,330**.
- Existing local build `_site`: 68 HTML files / 86,924,903 bytes. This includes generated output and must not be treated as tracked source.
- Core rendered routes measured from `_site`: 12 personal routes (`/`, `/zh/`, `/blog/`, `/zh/blog/`, four English + three Chinese article paths, `/404.html`). There are 21 useful blog year/tag/category archive routes generated by `jekyll-archives-v2`; the other 35 routes are template/demo output (books, projects 1–9, news announcements, CV, publications, repositories, teaching, plugins, people, dropdown, demo/relativity and Plotly).

### Medium-confidence simplify after feature inventory

- Remove unused feature gems and matching `_config.yml.plugins` in one change: `al_folio_cv`, `al_folio_distill`, `al_folio_upgrade`, `al_folio_bootstrap_compat`, `al_citations`, `al_ext_posts`, `al_img_tools`, `al_search`, `al_charts`, `al_math`, `al_newsletter`, `al_email_protect`, `al_marimo`, `al_rtl`; likely also Jekyll plugins for scholar, notebook, tabs, TOC, Twitter, imagemagick, archives, pagination, regex, JSON, ter-ser/minifier where no first-party page uses them. Keep `al_folio_core`, `al_icons`, `al_comments`, `jekyll-feed`, `jekyll-sitemap`, and the CSS/font/runtime dependencies until a minimal replacement is verified.
- Remove unused `third_party_libraries` catalog entries (Chart.js, D3, ECharts, Leaflet, MathJax, Mermaid, Plotly, Vega, etc.) only after grep of rendered HTML and source confirms no runtime consumer.
- Collapse `assets/css/editorial-site.css` only after browser snapshots; it is currently the only large first-party stylesheet (844 lines), so deleting selectors without route coverage is risky.

### Workflow/documentation candidates

Keep only a build/deploy workflow, a lightweight link/build check, and a targeted browser smoke test. The following are template-maintainer workflows and should be deleted or moved out if this repo is now a personal site: `deploy-image.yml`, `docker-slim.yml`, `deploy-docker-tag.yml`, `release.yml`, `render-cv.yml`, `update-citations.yml`, `update-tocs.yml`, `star-history.yml`, `upgrade-check.yml`, `visual-regression.yml`, `lighthouse-badger.yml`, `axe.yml`, `broken-links.yml`, `broken-links-site.yml`, `prettier-comment-on-pr.yml`, `prettier-html.yml`, `update-screenshots.yml`, and `copilot-setup-steps.yml`. Keep or replace `deploy.yml`, `unit-tests.yml`, `prettier.yml`, `codeql.yml` only if they are still desired.

Docs strongly tied to the starter (`docs/INSTALL.md`, `QUICKSTART.md`, `CUSTOMIZE.md`, `SHOWCASE.md`, plugin boundaries/architecture, upgrade docs) should be removed or rewritten for this site. Keep a short README and this repository's operational AGENTS.md.

## Minimal target workflow

1. `bundle exec jekyll build` (no baseurl override; site root is empty).
2. A single HTML/content smoke check covering `/`, `/zh/`, `/blog/`, `/zh/blog/`, one English article, one Chinese article, Giscus marker, and responsive portrait/QR lazy loading.
3. `npm run lint:prettier` only if Markdown/Liquid formatting remains enforced.
4. GitHub Pages deploy on `main`/`master`; cache-busted public checks after the workflow completes.

A full Docker, CV, Distill, plugin-toggle, scholar, fixture-parity, and 8-suite integration matrix is unnecessary once those features and their source are removed. Keep one browser mobile/desktop smoke test to prevent the arrow/mobile regression.

## Risks and verification gates

- Removing `jekyll-archives-v2` removes 21 tag/category/year routes; decide whether those URLs are product surface or intentionally eliminate them.
- Removing `jekyll-imagemagick` requires committing the responsive portrait WebP files or switching to the PNG/JPG source; otherwise the homepage image breaks.
- Removing `al_icons` or Font Awesome changes the three contact icons; replace with inline SVG or a small local icon set first.
- Removing `al_comments`/Giscus integration breaks the explicit repository-wide article feedback contract.
- Do not delete `assets/img/junjie-profile.PNG` until `junjie-profile-480.webp` and `junjie-profile-800.webp` are tracked or a new source path is chosen.
- Do not count `_site`, `node_modules`, `output`, `test-results`, `.jekyll-cache`, or `.bundle` as source bloat; they are generated/ignored local state.
